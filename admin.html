사이트에 반영하기

  1. faq.json 저장을 눌러 파일을 내려받습니다.
  2. GitHub 저장소 → data 폴더 → Add file → Upload files → 내려받은 faq.json을 끌어다 놓고 Commit changes.
  3. 1~2분 뒤 Q&A 페이지를 새로고침해 확인합니다.

⚠ 판단 기준은 규정·매뉴얼 원문이 우선합니다. 이 사이트의 설명은 이해를 돕기 위한 것입니다.
